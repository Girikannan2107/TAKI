TAKI Website Assets
===================

Source: supplied TAKI brand-board image.
All crops are raster exports from that board (not editable vector artwork).

Files:
- logo-primary: primary logo lockup with tagline
- logo-symbol: standalone location-pin symbol crop
- app-icon-light / app-icon-dark: light and dark app icons
- banner-hero: central website banner
- color-palette: palette swatches and hex labels
- typography: typography reference panel
- brand-icons: location, transport, cargo, reliable, sustainable, growth
- road-element / wave-element: supporting decorative graphics
- favicon: browser icon sizes and ICO

Formats:
- PNG: best general-purpose web format
- WebP: smaller modern web format
- JPG: fallback format for photographic/raster use

Brand colors:
--taki-primary: #173D32;
--taki-secondary: #286B50;
--taki-accent: #83B99A;
--taki-background: #F5F5EF;
--taki-text: #242B29;

Suggested usage:
Use PNG or WebP for logos and icons. Use WebP for large banner graphics.
The logo and supporting graphics are raster crops; request the original vector
artwork (SVG/AI/EPS) from the designer for lossless scaling and recoloring.
